A tiny stack VM for the [tiny-stack-vm-01-run-20261122 bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one `main.ts` (Node 22) runs all 40 instances of a set and writes each answer as `stdout.bin` + `exit.txt`. Practice set: **1,000,000/1,000,000** (baseline plain-vm 1.0.0: 670,000).
